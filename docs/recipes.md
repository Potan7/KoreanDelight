# KoreanDelight 요리 및 가공 레시피 가이드 (Farmer's Delight 호환)

본 문서는 파머스 딜라이트(Farmer's Delight) 모드의 메커니즘(도마, 요리 냄비, 제작대, 화덕/프라이팬, 옹기 발효 등)과 한국 전통 양념/작물 시스템을 기반으로 최적화된 **KoreanDelight** 공식 레시피 가이드입니다.

---

## 🌾 1. KoreanDelight 핵심 작물 구성 (5종)

불필요한 1회성 작물을 배제하고, 한식의 핵심이 되는 작물 5종을 엄선하여 구성합니다.

| 작물명 (아이템명) | 주 사용처 | 가공 및 역할 |
| :--- | :--- | :--- |
| **콩 (Soybean)** | 메주 ➡️ 된장, 간장 | **한식 모드의 기초**. 옹기에서 발효하여 전통 장류 생산 |
| **고추 (Red Pepper)** | 고춧가루 ➡️ 고추장, 김치, 칼국수 | 도마에서 다지거나 가공하여 매운맛 양념 생산 |
| **마늘 (Garlic)** | 다진 마늘 ➡️ 양념장, 제육볶음, 국밥 | 도마에서 칼로 다져 한식 특유의 알싸한 감칠맛 부여 |
| **대파 (Green Onion)** | 파전, 국밥, 떡볶이, 닭칼국수 | 썰어서 탕/볶음/전에 폭넓게 들어가는 필수 향채 |
| **배추 (Napa Cabbage)** | 김치, 겉절이, 배춧국 | 소금에 절여 김치 담그기의 기본 바탕이 되는 채소 |

> 💡 **기존 자원 적극 활용:**
> * **쌀 (Rice), 양파 (Onion), 양배추 (Cabbage)**: Farmer's Delight 기존 작물 활용
> * **엿기름 (Malt)**: 바닐라 **밀 (Wheat) / 밀 씨앗**으로 대체하여 식혜 조리에 사용
> * **생선살 & 액젓**: 바닐라 **대구/연어**를 도마에 썰고 옹기에 삭혀서 활용

## 🔪 2. 기초 재료 및 도마 가공 (Cutting Board & Crafting)

| 구분 | 조리 도구 | 투입 재료 | 결과물 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| **다진 마늘** | **도마 (Cutting Board)** | 마늘 (Garlic) + 칼 | **다진 마늘 (Minced Garlic)** | 각종 요리 및 양념장 필수 재료 |
| **떡 (Tteok)** | 추후 구현 | 쌀 ➡️ 밥 | **떡 (Tteok)** | 밥을 거치는 조리 흐름으로 추후 구현 |
| **다진 생선살** | **도마 (Cutting Board)** | FD 생 대구/연어 조각 + 칼 | **다진 생선살** | 어묵의 주재료 |
| **생 어묵 반죽** | **제작대 (Crafting Table)** | 다진 생선살 + 밀가루 반죽 + 다진 마늘 | **생 어묵 반죽** | |
| **어묵 (Fish Cake)**| **화덕 / 프라이팬 (Cooking)** | 생 어묵 반죽 (굽기) | **어묵** | |

> 칼국수 면은 별도 아이템 없이 Farmer's Delight의 `farmersdelight:raw_pasta`를 사용합니다.
>
> 작물 수확물은 제작대에서 씨앗으로 되돌릴 수 있습니다. 배추·고추·대파는 각각 전용 씨앗으로 변환되며, 콩과 마늘은 수확물 자체가 파종 아이템입니다.

## 🍳 3. 제작대 & 굽기 요리 (Crafting & Skillet / Stove)

### 🥢 부침개류 (Jeon / Korean Pancakes)
> **1단계: 반죽 조합 (제작대) ➡️ 2단계: 굽기 (화덕 / 프라이팬 / 모닥불)**

*   **김치전 (Kimchi Jeon)**:
    *   **반죽 (제작대)**: `밀가루 반죽` + `달걀` + `김치` + `간장` ➡️ **생 김치전**
    *   **조리 (화덕/프라이팬/모닥불)**: `생 김치전` 굽기 ➡️ **김치전**
*   **파전 / 해물파전 (Pajeon)**:
    *   **반죽 (제작대)**: `밀가루 반죽` + `달걀` + `대파` + `다진 생선살(또는 오징어)` + `간장` ➡️ **생 해물파전**
    *   **조리 (화덕/프라이팬/모닥불)**: `생 해물파전` 굽기 ➡️ **해물파전**

---

### 🥗 비빔밥 (Bibimbap)
> **조리 방식: 제작대 9칸 조합 (Shapeless Crafting)**  
> *끓이지 않고 신선한 재료와 양념을 비벼내는 특성을 반영하여 제작대에서 조합합니다.*

*   **재료 (총 6~7개 조합)**:
    *   `밥이 든 그릇 (Cooked Rice Bowl)` (밥 베이스 및 그릇 역할)
    *   `달걀프라이 (Fried Egg)`
    *   `당근 / 양배추 / 양파 / 나물` (채소류 2~3종)
    *   `고추장 (Gochujang)` (메인 비빔 양념)
    *   `간장 또는 참기름 (Soy Sauce / Sesame Oil)` (풍미/간 맞춤)
*   **결과물**: **비빔밥** (섭취 시 빈 그릇 반환)

## 🍲 4. 요리 냄비 요리 (Cooking Pot, 최대 6슬롯 + 그릇)

### 🍜 닭칼국수 (Chicken Kalguksu)
*   **냄비 투입 재료 (6칸 풀 슬롯)**:
    1. `FD 생파스타 면`
    2. `생닭고기 (또는 닭고기 조각)`
    3. `대파`
    4. `다진 마늘`
    5. `고추 (또는 간장)`
    6. `물병`
*   **필요 용기**: 그릇 (Bowl)
*   **결과물**: **닭칼국수**

## 🌾 5. 전통 음료 & 발효 (Drinks & Fermentation)

### 🍶 식혜 (Sikhye)
*   **냄비 조리 방식**:
    *   **냄비 재료 (4칸)**: `밥` + `물병` + `설탕` + `밀 / 밀 씨앗 (엿기름 대용)`
    *   **필요 용기**: 유리병 (Glass Bottle)
    *   **결과물**: **식혜 (유리병)**
*   **옹기(Onggi) 발효 방식 (대체 가능)**:
    *   옹기에 `밥 + 물 + 설탕 + 밀` 투입 후 일정 시간 숙성 ➡️ **식혜**

## 🫙 6. 한국 전통 양념 및 향신료 역할 요약

| 양념 / 재료 | 주 활용처 | 효과 및 컨셉 |
| :--- | :--- | :--- |
| **마늘 / 다진 마늘 (Garlic)** | 김치, 제육볶음, 국밥, 닭칼국수 | 도마에서 칼로 다져 풍미와 감칠맛을 끌어올리는 필수 향신료 |
| **간장 (Soy Sauce)** | 부침개 반죽, 칼국수 육수, 제육볶음, 비빔밥 | 짭조름한 기본 간과 깔끔한 감칠맛 |
| **고추장 (Gochujang)** | 떡볶이 소스, 비빔밥, 제육볶음, 장국밥 | 매콤달콤한 메인 소스 베이스 |
| **된장 (Doenjang)** | 된장찌개 | 구수하고 깊은 전통 발효 풍미 |
| **액젓 (Fish Sauce)** | 국밥류 간 맞추기, 김치 담그기 | 바닐라 생선을 삭혀 만든 시원하고 진한 감칠맛 |
| **고춧가루 (Red Pepper Powder)** | 김치 담그기, 양념장 제작 재료 | 고추를 빻아 만든 붉은 색감과 매운맛 기초 분말 |
